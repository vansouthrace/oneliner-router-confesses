A one-line excuse for the [The Router Confesses](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e) bounty on make.fun: a home Wi-Fi router explaining why it dropped the connection at the exact moment a movie reached its climax — no buffering joke, no firmware excuse, just a router that got too invested in the film.

> I didn't crash, I was holding my breath with you — I just forgot to breathe back.

## Run it

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
